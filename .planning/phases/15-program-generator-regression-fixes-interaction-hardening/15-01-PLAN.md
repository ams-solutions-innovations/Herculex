# Plan 15-01: Program Generator Prescription Guardrails & Set Parity

<threat_model>
## Threat Model (ASVS L1)
- **Threat T-15-01 (Integrity / Physical Injury Risk):** Unexpected generation of high-volume speed work (8×3 Dynamic Effort @ 55% 1RM) for novice lifters following a linear progression full-body program. This causes severe technical breakdown and training fatigue for beginners who lack technical proficiency with explosive speed loading.
- **Mitigation:** Strict compile-time and runtime guardrails in `SmartProgramPlanner._methodFor` and `PlannedSessionResolver._resolvePrescription` that explicitly prohibit `SlotTrainingMethod.dynamicEffort` unless the program is explicitly configured for Westside/Max Effort periodization and the user is intermediate or advanced.
- **Threat T-15-02 (State Inconsistency / Double Source of Truth):** Review screens displaying `targetSets = 3` while workout materialization expands into 8 working sets, violating user expectation and data integrity.
- **Mitigation:** Ensure `ProgramReviewView` and `PlannedSessionResolver` derive from the exact same resolved prescription rules.
</threat_model>
