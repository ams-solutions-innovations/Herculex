This plan imports `RepMovement`; it must never declare it. 10-02 Task 1 is a ~15-line enum file with no dependencies — if 10-01 and 10-02 share a working tree, run 10-02 Task 1 before this plan's Task 2.

## Trust Boundaries

| Boundary | Description |
|----------|--------------|
| Local DB → cloud sync outbox | The only boundary in this plan. A table wired into `syncedTableNames` or `syncTableSpecs` acquires an outbox trigger and its rows leave the device. |
| User consent state → feature surface | `consentGrantedAt` is the single authority for whether any rep-tracking code may run. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|------------------|
| T-10-01 | Information Disclosure | `tables.dart`, `sync_backfill.dart`, `sync_table_specs.dart` | mitigate | The three tables carry no `SyncColumns`/`SyncTombstone` and are absent from both sync lists; `test/rep_local_only_test.dart` asserts positively against `sqlite_master` that no outbox trigger exists on them (Task 1). |
