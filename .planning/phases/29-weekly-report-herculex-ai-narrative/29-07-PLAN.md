<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user-authored text -> prompt | food names (user text) enter the facts sent to the model |
| stored/pulled payload_json -> UI | remote-pulled snapshot text is untrusted |
| device -> Google Gemini | health-related aggregates leave the device (GDPR Art. 9) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-29-28 | Tampering | prompt injection via food names | mitigate | sanitizeText strips control chars/newlines, collapses whitespace, caps at 40; only 3 names; server prompt tells model to ignore embedded instructions |
| T-29-29 | Information Disclosure | over-sharing health data with the model | mitigate | Facts are aggregates only; no ids, notes, photos or raw samples; asserted by test; consent disclosure in plan 08 |
| T-29-30 | Tampering / DoS | malformed or future-version payload_json crashing the report | mitigate | Strict fromJson with FormatException on unknown version/wrong types; no `!` casts; UI error state in plan 18 |
| T-29-31 | Denial of Service | oversized facts rejected by server (wasted quota) | mitigate | Client reduction ladder keeps facts under 8000 chars before any call |
</threat_model>
