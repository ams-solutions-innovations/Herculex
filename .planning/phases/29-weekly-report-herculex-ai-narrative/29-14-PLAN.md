Create `weekly_report_service.dart`: `class WeeklyReportService { WeeklyReportService({required WeeklyReportRepository repository, required WeeklyReportInputsRepository inputs, required WeeklyReportNarrativeService narrative, required Clock clock, required Future<MacroTargets?> Function(DateTime day) targetForDay}) }` plus `sealed`/enum-style `NarrativeOutcome { saved, alreadySaved, notEligible, failed(kind) }` (a small value class with `NarrativeFailureKind? failure`). Methods:
- `Future<WeeklyReportRecord?> generate(IsoWeek week)`: (1) `existing = await repository.forWeek(week)`; if non-null return it unchanged (never recompute: D-01, RPT-04); (2) `now = clock.now()`; if `week.start.isAfter(now)` return null; (3) `windowEnd = week.windowEnd(now)` (D-04: Monday through the moment of generation; a missed week gets the full week and then freezes, D-05); (4) `inputs.load(week:, windowEnd:)`; (5) for each logged day call `targetForDay(day)` (wired in plan 15 to `effectiveTargetsProvider`) into `targetByDate`; (6) run `NutritionSectionCalculator`, `TrainingSectionCalculator`, `RecoverySectionCalculator`, `PhysiqueSectionCalculator`, and `TdeeShiftCalculator`; (7) build `WeeklyReportPayload(payloadVersion: 1, ...)`; if `!payload.hasSignal` return null (D-06); (8) `repository.insertSnapshot(week:, payloadVersion:, payloadJson: jsonEncode(payload.toJson()))` and return that record. The row is persisted before any AI work (D-02). Never swallow programmer errors silently; the controller (plan 15) is the fail-soft layer.
- `Future<NarrativeOutcome> generateNarrative(IsoWeek week)`: load the row; null or no `hasNarrativeSignal` (decode with `WeeklyReportPayload.tryDecode`) -> `notEligible`; `narrativeJson != null` -> `alreadySaved` with no backend call and no increment; otherwise `await repository.incrementNarrativeAttempts(week)` BEFORE the backend call (quota burn protection, RESEARCH Pitfall 2), then `narrative.generate(WeeklyReportFacts.fromPayload(payload))`; on success `repository.saveNarrative(week, narrativeJson: jsonEncode(narrative.toJson()), knowledgeVersion: provenance['knowledgeVersion'] as String?, modelVersion: provenance['modelVersion'] as String?)` (write-once) and return `saved`; on `WeeklyReportNarrativeException` return `failed(kind)`; any other error maps to `failed(NarrativeFailureKind.unavailable)`. This method writes only the narrative columns and the attempt counter; it has no access to nutrition targets or any other table (house rule: deterministic primary, AI bounded, AI never writes, user confirms).
Time comes only from the injected `Clock`.
