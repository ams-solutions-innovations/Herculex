<objective>
Close the timeline-realism gap (D-08-D-11, SPEC-03): hook the existing Weeks picker
(`dialogs.part.dart:_showLengthPicker`) so that, while a primary-lift specialization is active,
picking a weeks value shorter than `PrimaryLiftSpecialization.recommendedWeeks()` auto-adjusts the
pick back to the recommended value and shows an inline "not enough time" warning (D-08-D-10,
no new timeline field, any shortfall at all triggers it), and so that the same sheet separately
surfaces D-11's experience-aware kg-increase-ceiling warning (`ProgramGuardrails.validateKgIncrease`,
built in plan 22-01) whenever the user's current-to-target kg gap is unrealistic, independent of
which weeks value they pick.

Purpose: SPEC-03 requires unrealistic target timelines to generate a realistic warning rather than
silently accepting an aggressive pick; this plan is the only UI surface for that requirement.
Output: the Weeks picker auto-corrects an unrealistic weeks pick with an inline explanation, and
separately flags an unrealistic kg increase inside the same sheet, both non-blocking (D-05).
</objective>
