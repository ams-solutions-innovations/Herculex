# Plan 16-01: Schema v41 Migration, Drift Codegen & Asset Packaging

<threat_model>
## Threat Model (ASVS L1)
- **Threat T-16-01 (Asset Packaging / Silent Degradation):** If `assets/data/exercise_programming_metadata.json` is missing from `flutter.assets` in `pubspec.yaml`, Flutter release builds fail to bundle it. At runtime, `rootBundle.loadString` in `ExerciseImporter.runFromAsset` throws an exception that is swallowed by fallback handling, silently leaving every exercise in the database at conservative table defaults (`manualOnly`, `advanced`). This renders automated program generation non-functional on production devices.
  - **Mitigation:** Explicitly declare `- assets/data/exercise_programming_metadata.json` in `pubspec.yaml` under `flutter.assets:` and verify that asset loading works as expected in automated tests.
- **Threat T-16-02 (Schema Drift / Cloud Desynchronization):** Discrepancies between local SQLite Drift table definitions and remote Supabase PostgreSQL schema, or unverified migration steps between schema versions, can lead to failed database upgrades or sync errors for custom exercises.
  - **Mitigation:** Ensure exact column parity, conservative defaults (`manualOnly`, `advanced`), check constraints, and indexed traversal in both Drift (`tables.dart`, `database.dart`) and Supabase (`supabase/migrations/20260913000000_exercise_programming_metadata_v41.sql`). Verify both local SQLite migration replays (`test/migration_test.dart`) and cloud SQL schema assertions (`test/exercise_programming_metadata_supabase_migration_test.dart`).
</threat_model>

   alter table public.exercise_catalog
     alter column programming_commonness set default 'manualOnly',
     add column if not exists disciplines text not null default '[]',
     add column if not exists prerequisite_slugs text not null default '[]',
     add column if not exists scaling_group text,
     add column if not exists scaling_order integer,
     add column if not exists competition_anchor text,
     add column if not exists specialization_tags text not null default '[]';

   -- basic, common, specialty, manualOnly
   alter table public.exercise_catalog
     drop constraint if exists exercise_catalog_programming_commonness_check;

   alter table public.exercise_catalog
     add constraint exercise_catalog_programming_commonness_check
       check (programming_commonness in ('basic', 'common', 'specialty', 'manualOnly')) not valid;

   alter table public.exercise_catalog
     validate constraint exercise_catalog_programming_commonness_check;

   -- Scaling ladder index for indexed SQL ordering and traversal
   create index if not exists idx_exercise_catalog_scaling
