# Plan 14-01: Anthropometry Ratios & Profile Extensions

## Goal
Extend the user profile to support `inseam`, `arm_span`, and `torso` measurements, and create a Dart domain service to calculate anthropometric ratios (e.g., femur-to-torso, wingspan-to-height).

## Steps
1. Add `inseamCm`, `armSpanCm`, `torsoCm` fields to `Profile` model (with JSON serialization and Drift DB migration).
2. Add these fields to the `_body.part.dart` or `measurements_view.dart` so the user can input them.
3. Create `lib/features/profile/domain/anthropometry.dart` with functions to compute proportion ratios (e.g., short/long torso, long arms, etc).
