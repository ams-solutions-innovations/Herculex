# Plan 14-03: UI and Hercul Integration

## Goal
Surface the ergonomic guidance inside the Exercise Details view, and inject them as signals into the Hercul coaching engine.

## Steps
1. Modify `lib/features/exercises/presentation/exercise_detail_view.dart` to display an "Ergonomics" or "Proportions" section if guidance exists for the movement.
2. The UI should phrase guidance as a trade-off (e.g. "Because of your long femurs, you might find a low-bar position more comfortable...").
3. Ensure guidance is hidden if the user has not provided their height or relevant measurements.
4. Add new rules to `hercul_rules.json` that leverage the anthropometric ratios to offer insights on the dashboard card.
