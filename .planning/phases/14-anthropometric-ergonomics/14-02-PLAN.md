# Plan 14-02: Exercise Ergonomics Corpus

## Goal
Create the JSON corpus `assets/data/exercise_ergonomics.json` containing ergonomic guidance for specific movements based on anthropometric ratios.

## Steps
1. Create `assets/data/exercise_ergonomics.json`.
2. Key the JSON by `movementSlug` (e.g., `squat`, `deadlift`, `bench_press`).
3. Under each movement, provide guidance keyed by the ratios computed in 14-01, including sources for the guidance.
4. Add a loader/repository to read this JSON into memory, similar to `HerculEngine`.
