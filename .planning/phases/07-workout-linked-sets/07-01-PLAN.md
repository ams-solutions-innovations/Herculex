<objective>
Represent supersets and giant sets as linked workout exercises, make the relationship visible, support exercise reordering, and advance logging focus through linked exercises before starting rest.
</objective>

<tasks>

1. Add repository operations for exercise reorder, linking into `supersetGroup`, and unlinking.
2. Replace active workout list with a reorderable list and add a bottom-right delayed drag handle per exercise.
3. Render linked exercise groups with a left-side rail and group labels.
4. Add exercise menu actions to connect to another exercise or unlink from a group.
5. Move focus to the next linked exercise when a set is completed; start rest only after the final exercise in the linked group.
6. Remove `Giant Set` from the per-set type picker so new giant sets are created through exercise linking.
7. Add a repository regression test for linking, giant-set grouping, reorder, and unlink.

</tasks>

<success_criteria>

- User can connect two active workout exercises as a superset.
- Adding a third exercise to the same linked group presents it as a giant set.
- Linked exercises are visually connected with lines/nodes.
