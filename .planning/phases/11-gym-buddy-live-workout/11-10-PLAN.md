    - Flipping the toggle affects only that one action and does not change the default for the next

    - With no buddy session active, no scope control is rendered at all
  </behavior>
  <action>
    Create `lib/features/buddy/presentation/buddy_scope_toggle.dart` and wire it into the exercise
    mutation paths, routing the resulting `BuddyScope` into `BuddyChoreographySender`.

    Per the user's ruling this is a visible control with a sticky default, not a modal on every
    change. The default for remove is only-me precisely because remove is the destructive one — the

    A forced decision must show its reason. A control that silently ignores the user's choice is worse
