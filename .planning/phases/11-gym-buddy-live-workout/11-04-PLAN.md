<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated client → public schema | Untrusted RPC arguments and arbitrary PostgREST selects cross here |
| authenticated client → realtime.messages | Topic strings are client-chosen and must not be trusted or cast blindly |
| definer function → its own search_path | A mutable search_path in a definer function is a privilege-escalation vector |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-01 | Spoofing | leaked QR redeemed by a third party | high | mitigate | `buddy_join_session` gates on `expires_at <= now()` (10 min), `consumed_at is not null`, `buddy_sessions.ended_at is not null` and a live-participant cap of 2, all under `for update` |
| T-11-02 | Spoofing, Information disclosure | token enumeration / existence oracle | high | mitigate | `gen_random_uuid()` token (~122 bits CSPRNG), only `sha256(convert_to(token,'UTF8'))` stored, `buddy_join_tokens` RLS-on with zero policies plus `revoke all`, and one identical `invalid or expired join code` message for all five failure causes |
| T-11-03 | Tampering | forged event with a chosen `seq` | high | mitigate | `revoke insert, update, delete on public.buddy_session_events from anon, authenticated`; `seq` assigned inside `buddy_append_event` under `select next_seq ... for update` |
| T-11-04 | Tampering | a departed participant still mutating the shared list | high | mitigate | `buddy_append_event` re-checks `p.left_at is null and s.ended_at is null` on every call, independently of the Realtime policy cache |
