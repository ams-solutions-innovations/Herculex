plumbing that Phase 26 exists to establish (KB-01, KB-02). This is the foundational half of

parameter and a `modelVersion` return value through `generate()`/`generateJson()`/

existing Gemini kinds' JSON response. Per D-04, no kind is wired to consume an actual corpus
segment this phase — the injection path only needs to be provably wired and testable.

on, without touching today's 8 kinds' analysis behavior.
Output: `knowledge_base.ts` + `knowledge_base_test.ts` (new), `index.ts` widened with
`systemInstruction`/`modelVersion` threading, `index_test.ts` (new) covering both.
