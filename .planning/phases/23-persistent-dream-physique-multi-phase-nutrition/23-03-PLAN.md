<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| camera/gallery file -> app | an untrusted JPEG with embedded EXIF (GPS, device, timestamps) enters the app |
| ML Kit -> sanitiser | detector output (boxes) decides which pixels are blurred |
| synced `relative_path` -> filesystem | a string from another device resolves to a local file |
| app sandbox -> backup | documents-dir files may be included in OS backups |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-11 | Information Disclosure | EXIF GPS / device metadata in stored photos | mitigate | always decode, `bakeOrientation`, assign fresh `ExifData()`, drop ICC, re-encode; test asserts make and GPS absent after staging |
| T-23-12 | Information Disclosure | unblurred face persisted when blur requested | mitigate | blur applied to the temp file before `adopt`; the original face never reaches the sandbox; zero-face case reported, never claimed blurred (D-07) |
| T-23-08 | Tampering | path traversal through `resolve` | mitigate | reject empty, absolute, drive-letter, backslash, `..` and non-`physique` first segment; tested |
| T-23-13 | Denial of Service | decoding a very large JPEG on the UI isolate | mitigate | decode/resize/encode in `Isolate.run`; long side capped at 2048 stored and 1280 sent |
| T-23-14 | Information Disclosure | detector coordinates wrong on rotated source | mitigate | detect only on the already-baked EXIF-free temp file; manual rotated-sample device check in Plan 17 (A4) |
| T-23-15 | Information Disclosure | photos reaching OS cloud backup | accept | Android `allowBackup=false` verified in RESEARCH; iOS iCloud exclusion needs a Mac and is a tracked manual item in Plan 17 (A11) |
| T-23-SC | Tampering | new pub dependency `google_mlkit_face_detection` | mitigate | RESEARCH Package Legitimacy Audit: Approved (verified publisher `flutter-ml.dev`, same monorepo as an existing dependency); version pinned `^0.14.0` to avoid a native upgrade; lockfile commons/text-recognition versions re-checked after `pub get` |
