| Boundary | Description |
|----------|-------------|
| AI evidence -> verdict | the model's band and label are untrusted inputs to a deterministic classifier |
| device clock -> eligibility | a changed system clock influences the 7-day window (the repository, not this layer, is the real gate) |
| workout history -> chart | user-entered set data feeds e1RM; absurd values could distort a chart |
