| Boundary | Description |
|----------|-------------|
| client -> edge function | untrusted request body including base64 images and a context object |
| photo / user note -> Gemini prompt | text embedded in an image or note could try to steer the verdict (prompt injection) |
| Gemini -> client | model output is untrusted until whitelisted |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-23-17 | Tampering | prompt injection through image text or `userNote` | mitigate | prompt states to ignore conflicting embedded instructions; output whitelisted by `normalizePhysiqueCheckinResult`; model has no write access; Dart classifies the verdict (Plan 05) |
