<objective>
Build the GoRouter widget-test harness that Plan 20-03 (FLOW-02) and Plan 20-04
(FLOW-03) need. No test in this repository currently pumps a widget under
`MaterialApp.router`/exercises `context.push` — `DayDetailSheet` is only ever
tested with a bare `MaterialApp(home: Scaffold(...))` today
(`test/widgets/day_detail_sheet_test.dart`). Once `DayDetailSheet._viewWorkout`
and the new `PlannedWorkoutPreviewView` start calling `context.push`, that gap
becomes a hard test-authoring blocker (RESEARCH.md Pitfall 2).

Purpose: give every later plan in this phase a reusable, dependency-free way to
pump a widget under a real `GoRouter` and assert on pushed routes via stub
screens, without needing the real destination screens or any not-yet-created
`AppRoutes` constants to exist yet.
Output: `test/support/go_router_test_harness.dart` (harness) +
`test/support/go_router_test_harness_test.dart` (self-test proving it works).
</objective>
