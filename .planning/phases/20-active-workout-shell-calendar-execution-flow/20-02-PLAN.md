<objective>
Extract the duplicated keyboard/focus-driven chrome-hiding logic in
`MainScaffold` (nav bar) and `ActiveWorkoutView` (floating action bar) into one
reusable `design_system/components/` primitive: `KeyboardObstructionScope`
(FLOW-01, D-01–D-03).

Purpose: any future bottom-anchored control that must clear the keyboard/
focused-input area gets this behavior for free, instead of every consumer
hand-rolling its own `AnimatedPositioned` → `ExcludeSemantics` →
`IgnorePointer` → `AnimatedOpacity` stack.
Output: `KeyboardObstructionScope` widget + both existing consumers rewired to
use it, with the Phase 15 regression test
(`test/widgets/active_workout_keyboard_test.dart`) passing unchanged.
</objective>
