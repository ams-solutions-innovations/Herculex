<objective>
Fix the real routing bug FLOW-03 names: `DayDetailSheet._viewWorkout`
currently always shows the *planned* preview regardless of `row.status`, so a
completed day's "View workout" shows the plan instead of what was actually
logged — even though `schedule.completedSessionId` already links to the real
session (D-06/D-07/D-08).

`WorkoutHistoryView(sessionId: completedSessionId)` (the single source of
truth — `.planning/PROJECT.md`), while `planned`/`moved`/`skipped` rows keep
routing to `PlannedWorkoutPreviewView` (built in Plan 20-03) unchanged.
Output: `ScheduledWorkoutRow.completedSessionId` getter + status-gated
`_viewWorkout` routing + regression tests for all four reachable statuses.
</objective>
