<objective>
Wire D-04's visible-gap requirement into the actual program review screen: a day with an empty slot
(per Wave 3's `ProgramSlotExplanations` rows) shows the planner's own rationale text inline, instead of
that slot just silently not existing in the rendered exercise list.

Purpose: Waves 1-3 make empty slots a real, persisted, explainable outcome — but nothing reads
`ProgramSlotExplanations` yet. Without this plan, an empty slot is invisible to the user: `_DayCard`
today only renders `day.exercises` (sourced from `ProgramDayExercises`, which an empty slot never
gets a row in), so the day would just look one exercise short with no explanation, which is exactly
the "invisible gap" D-04 exists to prevent.
Output: `program_review_view.dart`'s `_load()` also fetches empty-slot explanations for the selected
week, and `_DayCard` renders one `EmptySlotNotice` (from Wave 0) per empty slot on that day, alongside
the existing `_ExerciseRow`s for filled slots.
</objective>
