<objective>
Build HerculexAiBriefService: the data-layer service that owns the full generate -> parse -> persist -> read lifecycle for Herculex AI program briefs, modeled directly on DreamPhysiqueService (the closest existing analog in this codebase for "call Gemini, parse strictly, translate failures into a UI-facing exception"). This is the ONLY code path that writes to or reads from HerculexAiProgramBriefs - block_builder_view.dart (plan 27-11/27-13) and program_review_view.dart (plan 27-12) both call into this service rather than touching drift directly, closing the pre-existing "UI touches drift directly" anti-pattern RESEARCH.md flagged in DreamPhysiqueService's own view code (this phase must not repeat it).

Purpose: single, testable seam between the Gemini backend, the strict Dart parser, and local persistence - both consuming UI plans get a clean three-method contract.
Output: HerculexAiBriefService with generateBrief() (network + parse + AIP-05 exception translation), persistBrief() (writes to HerculexAiProgramBriefs via drift, Clock-injected timestamp), and watchBriefForProgram(programId) (StreamProvider-friendly read for the review screen).
</objective>
