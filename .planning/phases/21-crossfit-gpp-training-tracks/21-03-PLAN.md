<objective>
Two independent, small, additive changes that unblock CF-01 and CF-02 without touching any shared file from the other Wave 1 plans: (1) extend `WorkoutDurationEstimator` with a fixed/capped-duration method for AMRAP/EMOM/For-Time metcon segments, and (2) curate the `prerequisiteSlugs` metadata gap RESEARCH.md found — `kipping-muscle-up`, `strict-muscle-up`, and all 6 Olympic-tagged lifts currently have empty `prerequisiteSlugs` despite Phase 16's own stated intent (front-squat/overhead-press -> clean & jerk) never having been shipped.

Purpose: Without (1), a metcon's fixed duration would be estimated via the per-rep formula (`workingSets x (reps x secondsPerRep + restSeconds)`), which is meaningless for "as many rounds as possible in 10 minutes." Without (2), CF-02's "prerequisite-gated skill/scaling selections" success criterion is unverifiable against the blueprint's own named examples (muscle-up, snatch complex) because the underlying data has no gate to test.
Output: `WorkoutDurationEstimator.estimateCappedSegment`; 8 curated `prerequisiteSlugs` entries in the metadata JSON; extended `exercise_scaling_resolver_test.dart` coverage proving the new gates work.
</objective>
