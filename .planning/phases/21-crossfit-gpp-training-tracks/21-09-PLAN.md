<objective>
Close VERIFICATION.md gap #2 for Phase 21: `smart_program_planner.dart` deliberately persists placeholder `targetSets=1/targetRepsMin=1/targetRepsMax=1` for CrossFit metcon rows (the real AMRAP/EMOM/For-Time prescription lives separately in `prescriptionCodecJson`, encoded via `SlotPrescriptionCodec`). `lib/features/programs/presentation/views/program_review_view.dart`'s `_ExerciseRow` (currently line 618, subtitle text built at line 658) renders those raw placeholder columns directly with zero reference to `prescriptionCodecJson`, so every generated CrossFit metcon movement shows "1 sets · 1 reps" in the program review/edit screen -- even though the real cap is correctly threaded through to the active workout (per plan 21-07's `planned_session_resolver.dart` work, which is independently verified correct).

Purpose: Make the program review screen's metcon display match what the athlete will actually do, by decoding the same `prescriptionCodecJson` column the active-workout path already decodes correctly, and rendering a real AMRAP/EMOM/For-Time summary instead of the meaningless placeholder.

Output: `_ExerciseRow` decodes `prescriptionCodecJson` via `SlotPrescriptionCodec.decode` whenever `item.row.sessionSegment == SessionSegment.metcon.id`, and renders a real one-line summary (e.g. "AMRAP 7:30", "EMOM 12 min", "For Time, cap 9:00") in place of the `'${item.row.targetSets} sets · $reps'` placeholder text for those rows only. Non-metcon rows are untouched. A new widget test proves the placeholder text is gone and the real summary renders for a seeded metcon row.
