    Create `lib/features/workouts/domain/workout_duration_estimator.dart` as plain Dart (imports only `set_type.dart` and `warmup_resolver.dart`). Define `abstract final class WorkoutDurationEstimator` with two static methods:

    `static Duration estimateExercise({required int workingSets, required int repsMin, required int repsMax, required int restSeconds, required SetType setType, List<WarmupStep> warmupSteps = const [], bool isUnilateral = false})` — itemizes (D-06): (a) working-set time = `workingSets * (avgReps * secondsPerRep + restSeconds)` where `avgReps = (repsMin + repsMax) / 2` and `secondsPerRep = 3.5`; unilateral work doubles the rep-performance component only (`avgReps * secondsPerRep * 2`), rest stays per-set (matches "unilateral work counted at 2x per side"); (b) warmup time = sum over `warmupSteps` of `reps * secondsPerRep + 30` (30s warmup-specific inter-step rest); (c) mini-set burst time — when `setType.metaKeys.contains('miniSets')` (covers `restPause`/`myoReps`), add `2 * (avgReps * 0.4 * secondsPerRep + 15)` (two extra mini-bursts at ~40% of the primary rep count with 15s intra-burst rest, modeling `restPause`/`myoReps`'s declared `miniSets` behavior without needing the actual runtime `meta` value at estimate time). Sum (a)+(b)+(c), return as `Duration(seconds: ...round())`.

    `static Duration estimateSession(Iterable<Duration> exerciseDurations, {int transitionSecondsPerExercise = 90})` — returns `exerciseDurations.fold(Duration.zero, (sum, d) => sum + d) + Duration(seconds: exerciseDurations.length * transitionSecondsPerExercise)`.
