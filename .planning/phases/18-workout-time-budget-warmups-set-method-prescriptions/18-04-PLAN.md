<objective>
Rewrite `PlannedSessionResolver.resolveProgramDay`'s two ad-hoc data sources — the `templateSets` JSON blob (`_copiedTemplateSets`) and the fixed warmup tables (`_automaticWarmups`, `_maxEffortSets`) — to read through `SlotPrescriptionCodec` (D-01/D-04) and `WarmupResolver` (D-08/D-09/D-10) instead. This method is already the single call site both `previewScheduledWorkout` (calendar "View workout") and `startScheduledWorkoutById` (actual session start) go through (`scheduled_workout_service.dart` lines 137, 175), so making it read through the codec is what makes preview/session byte-parity (D-02, PRES-01) structurally guaranteed rather than something to separately re-prove in the UI layer.

Purpose: Single canonical read path for prescriptions and warmups.
Output: Updated `planned_session_resolver.dart`; `_automaticWarmups`, `_maxEffortSets`, `_copiedTemplateSets` removed.
</objective>
