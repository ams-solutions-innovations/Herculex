<objective>
Make program generation honor the user's time budget for real (D-05, D-06, D-07, PRES-02): compute an itemized per-day duration estimate via `WorkoutDurationEstimator` after all of a day's slots are planned, and if it exceeds `workoutDurationMinutes * 1.10`, trim accessory/isolation slots (reduce set counts, then drop entirely) — never `SlotRole.main`/`supplemental` — until the day fits or no more accessory/isolation slots remain.

Purpose: Close the loop between the user's declared time budget and what actually gets generated; make the opt-in durable past generation time.
Output: Updated `smart_program_planner.dart` with a two-pass per-day trim loop, codec-based writes, persisted opt-in.
</objective>
